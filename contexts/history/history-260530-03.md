# implemented

- `input.html` の `applyPlaceTitle()` が active place を返すようにし、読み込み失敗時は `null` を返すようにした。
- 送信前に active place が解決できていることを確認し、場所情報がないまま `messages` 投稿しないようにした。
- 位置情報取得を Promise 化し、失敗時は従来通り福知山駅座標に fallback する構造へ整理した。
- Apps Script の応答本文を確認し、HTML、空応答、error 系の応答、成功確認できない応答では `送信しました` を表示しないようにした。

# decisions

- 書き込み先は引き続き Apps Script Web App `GAS_URL` 経由とする。
- `fetch` の HTTP status だけでは Spreadsheet への append 成功とみなさない。
- UI追加は行わず、既存の alert に失敗理由を出す。
- `places` 読み込みができない場合は、空の `placeId` で投稿しない。

# unresolved

- Web App が HTML を返す場合、公開設定、実行ユーザー、認可、またはログイン要求の問題が残る。
- Apps Script が成功時に `ok` / `success` / JSON success を返していない場合、Web App 側の返答形式を合わせる必要がある。
