# decisions

- 書き込み経路は既存の Apps Script Web App `GAS_URL` を維持する。
- UI追加や Google Sheets 直書き API の導入は行わない。
- `placeName` は `locationLabel` を優先し、未設定時のみ `name` / `placeId` に fallback する。
- `weight` は従来の最小値として `1` を送信する。
