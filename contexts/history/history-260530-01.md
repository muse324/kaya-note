# title

# date

# implemented

- `view.html` の `introStartTime` を Google Sheets の places / messages 読み込み完了後に開始するよう変更し、非同期ロード前に intro が進行しないようにした。
- place filter により `inputHistory` が空の場合でも、active place の title / name、または `かやのおと` を fallback として intro に表示するようにした。
- `pickIntroLog()` は recent queue に含まれない text を優先し、候補が尽きた場合のみ直前 text を避ける fallback にした。
- intro text の出現位置について、直近位置の保持数と再抽選条件を少し強め、過剰な重なりを抑制した。

# decisions

- UI追加、ライブラリ追加、構造的リファクタは行わない。
- Google Sheets 読み込み後に intro の時間計測を始めることで、既存の `intro → silence → main → guide` 構造を維持する。
- message がない place では過去の記憶を捏造せず、場所名由来の fallback 表示に留める。
- text 配置は grid や collision engine にせず、確率的な再抽選だけで organic な揺らぎを残す。
