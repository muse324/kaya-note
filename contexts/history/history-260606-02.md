# title

現地視認性検証モード（FIELD_TEST_MODE）の追加

# date

2026-06-06 00:45

# implemented

- view.html の先頭に `FIELD_TEST_MODE` 定数を追加（デフォルト: false）
- FIELD_TEST_MODE = true 時、テキスト透明度を 1.4 倍に向上
- FIELD_TEST_MODE = true 時、テキストサイズを 1.3 倍に拡大
- FIELD_TEST_MODE = true 時、層の breathing 効果を 85-115% から 95-105% に縮小し、安定表示を実現
- FIELD_TEST_MODE = true 時、ガイドテキストの透明度を 180 から 255 に上昇させ、タイトル/説明文/入力案内のサイズを各 1.2/1.1/1.2 倍に拡大
- 既存の作品表現（背景、intro 演出、音響、色彩変化）は保持

# modified_files

- view.html

# decisions

- `FIELD_TEST_MODE` をグローバル定数にすることで、屋外テスト時に簡単にオン/オフ可能にした
- 視認性向上の手法を「透明度・サイズ・安定性」の3軸に整理し、それぞれ段階的に調整
- breathing 効果は完全に排除せず、微弱に残すことで「漂う」表現を部分的に保持
