# History File Format

Filename:

history-YYMMDD-XX.md

Example:

history-260525-01.md

Language: Japanese

---

# Required Sections

# title

Short implementation title.

# date

YYYY-MM-DD HH:mm

# implemented

Implemented features.

# modified_files

Modified file list.

# decisions

Architecture or implementation decisions.

# unresolved

Remaining issues or postponed tasks.

# next_steps

Recommended next tasks.

---

# Rules

- Keep concise
- Prioritize restartability
- Avoid long conversational logs
- Include exact filenames/routes/models when relevant
- Write for future handover
- Prefer implementation facts over commentary
