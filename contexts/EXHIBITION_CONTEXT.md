# EXHIBITION_CONTEXT

## 展示前提

「かやのおと」は、
通行型空間での展示を前提とする。

鑑賞者は立ち止まらない可能性が高い。

---

## 空間条件

- 白壁環境
- 投影が負けやすい
- ネット素材（蚊帳）使用
- 背後黒層を想定
- 屋内外の変動あり

---

## 技術条件

- localhost運用
- p5.js中心のHTML構成
- Web Audio API
- Google Sheets / Apps Script 連携を正式採用
- ネットワーク接続を展示運用条件に含める
- Chrome依存あり
- fullscreenはブラウザ制約に従う

---

## 重視すること
